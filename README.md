# Finlog · Demo

**목표를 정하면, 이번 월급의 사용 계획이 보입니다.**

여행, 이사, 새로운 도전처럼 나에게 의미 있는 목표를 향해 쓸 돈과 모을 돈을 나누는 가계부입니다. 이 브랜치는 **GitHub Pages에서 로그인 없이 둘러볼 수 있는 체험 버전**을 제공합니다.

## 이렇게 둘러보세요

1. 첫 화면에서 **‘데모 시작하기’**를 눌러 주세요.
2. 홈에서 남은 생활비·하루 기준 예산·목표 진행률을 확인해요.
3. **‘지출 기록’**으로 금액과 항목을 입력하고 달라진 생활비를 살펴봐요.
4. **‘내 목표’**에서 저축·목표 자금 사용을 기록하거나 목표 조건을 바꿔 봐요.
5. **‘월급 계획’**에서 저축과 여유 자금을 조정하고 변경 전후를 비교해요.

모바일에서는 하단 메뉴로 이동하고, PC에서는 왼쪽 메뉴로 화면을 전환할 수 있어요.

## 체험할 수 있는 기능

| 화면 | 체험 내용 |
| --- | --- |
| 홈 | 남은 생활비, 하루 기준 예산, 목표 진행률, 예정 지출, 최근 기록 |
| 기록 입력 | 지출·저축·필수 지출 납부·추가 수입·목표 인출·목표 자금 사용 |
| 내 목표 | 저축 현황, 목표 조건 변경, 달성 예상일 확인 |
| 기록 | 종류·항목별 조회, 기록 수정·취소 |
| 월급 계획 | 목표 저축·여유 자금 조정, 생활비 변경 미리보기 |
| 설정 | 월급 정보 입력 체험, JSON·CSV 다운로드, 예시 데이터 초기화 |

이미 배정한 저축과 예약한 필수 지출은 실제 기록할 때 생활비에서 다시 차감되지 않아요. 배정액보다 더 저축할 때는 생활비가 얼마나 줄어드는지 먼저 확인할 수 있어요.

## 체험 전에 알아두세요

- **모든 초기 금액과 기록은 가상의 예시입니다.** 실제 개인정보나 금융 정보를 입력하지 마세요.
- 변경 내용은 현재 페이지에서만 유지되며, **새로고침하거나 새 탭으로 열면 초기화**돼요.
- 입력한 기록은 서버에 전송하거나 브라우저에 영구 저장하지 않아요.
- **‘처음부터 다시 체험’**을 누르면 언제든 예시 데이터로 돌아갈 수 있어요.
- 로그인·회원가입·첫 설정·반복 지출 저장·기간 마감·백업 복원·기기 간 동기화는 제공하지 않아요.
- 내려받은 파일은 체험 기록 확인용이며, 실제 서비스의 계정 백업으로 사용할 수 없어요.
- 생활비와 달성 예상일은 입력한 기록과 계획에 따른 참고값이며 실제 은행 잔액과 달라요.

## 내 컴퓨터에서 실행하기

Node.js 24 이상이 설치된 환경에서 실행해 주세요.

```sh
npm install
npm run dev
```

브라우저에서 **http://localhost:5173** 으로 접속하세요. Windows PowerShell에서 실행이 제한되면 `npm` 대신 `npm.cmd`를 사용하세요.

빌드 결과를 확인하려면 다음 명령을 실행해 주세요.

```sh
npm run build
npm run preview
```

## GitHub Pages에 공개하기

이 브랜치는 `github-pages`이며, 배포에 필요한 GitHub Actions 워크플로가 포함되어 있습니다. **파일을 수정한 것만으로 공개 배포가 완료되는 것은 아닙니다.**

1. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
2. `github-pages` 브랜치에 변경 사항을 커밋하고 푸시합니다.
3. **Actions → Deploy Finlog demo**에서 배포 결과를 확인합니다.
4. 배포 성공 후 **Settings → Pages**에 표시되는 주소를 공유합니다.

현재 저장소의 기본 예상 주소는 `https://hobe0m.github.io/Finlog/`이며, 실제 주소와 공개 여부는 배포 결과에서 확인하세요. 배포 환경의 허용 브랜치 제한이 있다면 `github-pages` 브랜치를 허용해야 합니다.

화면 주소는 `#/app`, `#/app/goal`처럼 구성되어 하위 화면의 주소 공유와 새로고침을 지원합니다. `github-pages`의 데모 전용 변경은 실제 서비스용 `main`·`dev`에 병합하지 않습니다.

배포 설정 참고: [GitHub Pages 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## 검증

```sh
npm test
npm run build
npm run test:browser
```

브라우저 테스트는 빌드 후 실행하며, Windows에서는 Microsoft Edge를 사용합니다. 다른 환경에서는 Playwright Chromium을 설치해야 합니다. 별도 API 없이 `/Finlog/` 하위 경로에서 화면 이동·새로고침·입력·수정·취소·모바일 레이아웃을 확인합니다.
