# Finlog

**목표를 정하면, 이번 월급의 사용 계획이 보입니다.**

여행, 이사, 새로운 도전처럼 나에게 의미 있는 목표를 정해 보세요. Finlog는 월급에서 쓸 돈과 모을 돈을 나누고, 일상의 기록을 통해 목표에 얼마나 가까워졌는지 보여주는 가계부입니다.

## Finlog로 할 수 있는 일

| 화면 | 이런 순간에 사용해요 |
| --- | --- |
| 홈 | 남은 생활비와 하루 기준 예산을 확인하고 싶을 때 |
| 내 목표 | 지금까지 모은 돈과 앞으로의 저축 계획을 살펴볼 때 |
| 기록 | 지출과 저축을 남기거나 지난 내역을 돌아볼 때 |
| 월급 계획 | 필수 지출·목표 저축·여유 자금의 배분을 조정할 때 |
| 설정 | 월급과 반복 지출을 바꾸거나 내 기록을 내보낼 때 |

PC에서는 계획과 내역을 넓게 살펴보고, 모바일에서는 하단 메뉴와 기록 입력창으로 간편하게 사용하세요.

## 나만의 계획 시작하기

1. **월급과 현재 상황을 알려 주세요.** 월급일과 배분할 수 있는 돈을 입력해요.
2. **먼저 나갈 돈을 챙겨요.** 월세·통신비처럼 예정된 필수 지출을 등록해요.
3. **나에게 의미 있는 목표를 정해요.** 목표 금액과 이미 모은 돈을 입력하고, 목표 날짜 또는 월 저축액으로 계획해요.
4. **생활비를 확인해요.** 저축과 여유 자금을 나눈 뒤 사용할 수 있는 금액을 확인해요.
5. **일상을 기록해요.** 지출과 실제 저축을 남기며 계획을 이어가요.

현재 월급 기간부터 시작하거나 다음 월급부터 시작할 수 있어요. 현재 기간부터 시작한다면 목표에 이미 모은 돈은 제외하고, 지금 배분할 수 있는 돈과 아직 내지 않은 필수 지출을 입력해 주세요.

## 예시로 먼저 둘러보기

첫 화면의 **‘예시로 먼저 둘러보기’**를 선택하면 로그인 없이 가상의 가계부를 체험할 수 있어요.

- 남은 생활비와 목표 진행 상황 살펴보기
- 지출·저축·필수 지출 납부 기록하기
- 기록 수정·취소와 항목별 조회
- 목표 조건과 월급 배분 바꿔 보기
- 예시 기록을 파일로 내려받기

**예시 체험에서 변경한 내용은 새로고침하면 초기화돼요.** 실제 계정의 기록과는 섞이지 않아요. 첫 설정, 기간 마감, 반복 지출 저장, 백업 복원은 예시 체험에 포함되지 않으며, 목표 달성 일정 등 일부 계산은 실제 사용과 다를 수 있어요.

## 기록할 때 알아두면 좋아요

### 저축할 돈과 실제로 모은 돈을 구분해요

월급 계획에서 정한 저축액은 미리 확보해 둔 예산이에요. 실제로 돈을 옮긴 뒤 저축 기록을 남기면 목표에 모인 금액이 늘어나요. 이미 배정한 저축액은 생활비에서 다시 빠지지 않아요.

### 필수 지출은 납부만 기록하면 돼요

예정된 지출의 **‘납부 기록’**을 선택해 주세요. 미리 반영한 금액과 같은 금액을 납부했다면 생활비는 그대로예요. 실제 납부액이 다를 때는 그 차이만 반영돼요.

### 목표 자금도 상황에 맞게 사용할 수 있어요

모은 돈을 생활비로 돌리거나 목표를 위해 직접 사용한 내역을 남길 수 있어요. 목표를 달성한 뒤 자금을 사용해도 달성 이력은 보존돼요.

### 한 기간을 돌아보고 다음 계획을 세워요

월급 기간이 끝나면 미납 지출과 저축 내역을 확인하고 마감할 수 있어요. 남은 생활비나 부족액은 다음 계획에 반영돼요. 실제로 저축하지 않은 금액을 모은 돈으로 표시하지 않아요.

## 내 기록 보관하기

로그인해 저장한 기록은 새로고침 후에도 유지돼요. 같은 서비스에 같은 계정으로 접속하면 다른 기기에서도 확인할 수 있으며, 다른 곳에서 변경한 내용은 새로고침하면 반영돼요.

설정에서 기록을 파일로 내려받을 수 있어요.

- **CSV:** 거래 내역을 스프레드시트에서 살펴볼 때
- **JSON:** 전체 자료를 백업하고 나중에 복원할 때

복원 전에는 포함된 기록과 금액을 미리 확인할 수 있어요. **복원하면 현재 자료가 백업 자료로 교체되므로**, 먼저 현재 기록을 내보내 주세요.

## 현재 이용 범위

Finlog는 사용 흐름을 확인하고 개선하는 초기 버전이에요. 공개 체험 주소는 아직 준비 중입니다.

- 원화 기준으로 정기 월급 1개와 활성 목표 1개를 관리해요.
- 은행·카드 내역은 자동으로 가져오지 않으며 직접 기록해요.
- 표시되는 생활비는 기록과 계획에 따른 예산으로, 실제 은행 잔액과 다를 수 있어요.
- 신용카드는 구매일에 지출을 기록하고, 카드 대금 납부를 같은 소비로 다시 기록하지 않아요.
- 마감한 기간의 기록 수정과 오프라인 입력은 현재 지원하지 않아요.

## 내 컴퓨터에서 체험하기

Node.js 24 이상이 설치된 환경에서 프로젝트 폴더를 열고 실행해 주세요.

```sh
npm install
npm run dev
```

브라우저에서 **http://localhost:5173** 으로 접속한 뒤 **‘예시로 먼저 둘러보기’**를 선택하세요. 사용하는 동안 실행한 터미널을 열어 두어야 해요.

Windows PowerShell에서 명령 실행이 제한되면 `npm` 대신 `npm.cmd`를 사용해 주세요.
